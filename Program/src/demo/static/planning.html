人力投入

每組填寫全職標準下「每人每月」的現金支出及額外未付勞動估值，系統再乘人數與投入比例。未付估值只填沒有包含在現金支出的部分；不計估值時明確填 0。請勿在其他開支重複計入同一筆薪酬。

其他投入

手動金額使用上方幣別，切換幣別不會換算手動數值；已選外幣費用須重新填寫換算率及確認。不適用的必要支出請填 0；漏填不會自動當作零。

選用費用如何計入

完整收費期已計入；金額按你填寫的換算率換算。每個延期情境會重新計算續期費用。原始價格、資格確認、換算率及來源會隨 JSON 匯出。

資金與回本要求

回本份數是按輸入假設計算的要求，不是預測銷量或成功機率。資金可支持月數先預留一次性開支、全額備用金及選用費用，再按固定每月支出計算，假設沒有收入。選用付費項目時，結果最多顯示至本情境工期；這不是逐月付款時間表。

未付勞動估值獨立列出，不影響現金支出或現金可支持月數。結果不含未輸入的維護、移植、個人生活費等項目；需要時請在相應成本欄位納入。金額顯示四捨五入至兩位小數。
