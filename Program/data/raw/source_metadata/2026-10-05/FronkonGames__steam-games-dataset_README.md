# Steam Games Dataset

Information of **143,395** games published on Steam.

This dataset has been created with [this code](https://github.com/FronkonGames/Steam-Games-Scraper) (MIT) and use the API provided by Steam, the largest gaming platform on PC. Data is also collected from Steam Spy. **Only published games**, no DLCs, episodes, music, videos, etc.

**Maintained by [Fronkon Games](https://github.com/FronkonGames).**
